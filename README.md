# Dylan Couch portfolio

Static, build-free portfolio site for GitHub Pages.

## Preview locally

From this directory, run:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Publish

The site uses only `index.html`, `styles.css`, and local image assets. GitHub Pages is configured to deploy the repository root from the `main` branch; no build step is required.

## Content and assets

Experience, education, and selected project details come from Dylan Couch's supplied résumé. Social icons are stored locally in `images/`. Contact email is `dylancouch@gmail.com` as provided for this site.
